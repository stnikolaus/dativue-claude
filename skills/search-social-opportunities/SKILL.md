# Dativue search and social opportunities

Use this workflow when neither keyword metrics nor social posts alone can answer the question.

1. Plan keyword ideas, one trend comparison, one live SERP for each final query, and only the social networks relevant to the audience.
2. Run routine calls directly. Use `research_credit_quote` when the user asks for an estimate or a large plan needs a spending bound. Get approval for any search call whose maximum hold exceeds 50 credits.
3. Discover candidates with `search_keyword_ideas`, then use `search_keyword_trends` and `search_serp` to validate the shortlist.
4. Use `social_search`, `social_comments`, or `social_posts` to test whether people currently discuss the need, wording, objections, and successful formats.

Return an opportunity table containing keyword, measured volume, difficulty, intent, calculated trend direction, current SERP pattern, social evidence, audience language, source links, and recommended angle. Mark unavailable metrics `N/A`. Distinguish measured search data, retrieved social evidence, calculations, and conclusions.
