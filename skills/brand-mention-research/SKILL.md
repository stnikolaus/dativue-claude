# Dativue brand mention research

Run routine research without a quote. Estimate with `research_credit_quote` when asked, and get user approval for any call whose maximum hold exceeds 50 credits.
Use the smallest preset that can answer the user's timeframe and coverage question.

Preserve URLs, excerpts, language, country, dates, ratings, categories, and provider sentiment or emotion labels when available.
Keep provider classifications separate from calculated patterns and conclusions.
Write `N/A` for missing data and state that coverage is not a complete index of the web.
Do not use mention research for personal-data enrichment.
