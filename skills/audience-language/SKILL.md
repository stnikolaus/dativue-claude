# Audience-language mining

Use this workflow when the user provides public posts/videos or asks how an audience describes a problem.

1. Gather the exact public post/video URLs. Do not infer or expose private identity attributes.
2. Retrieve comments directly. Use `research_credit_quote` when the user asks for an estimate or the planned work may exceed 50 credits, and get approval for a higher-cost plan.
3. Retrieve up to 50 comments/replies per approved URL. Treat the sample as directional, not a representative survey.
4. Cluster repeated questions, objections, desired outcomes, emotional language, misconceptions, and phrases people naturally use.
5. Quote only short phrases necessary to demonstrate language patterns and avoid unnecessary usernames or personal information.
6. Cite the source post for every cluster and recommend message/content angles that are explicitly grounded in the observed comments.

Default maximum: 24 credits for four source URLs at the highest current comment price.
