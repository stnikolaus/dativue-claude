# Dativue keyword research

Use `search_keyword_ideas` for measured Google keyword data. Default to United States and English only when the user has not named another market.

Run routine research without a quote. Estimate with `research_credit_quote` when asked, and get user approval for any call whose maximum hold exceeds 50 credits.

Cluster useful terms by shared topic and intent. For every shortlisted keyword, report search volume, keyword difficulty, and intent; write `N/A` when Dativue returns no value. Label these as measured provider metrics and never manufacture missing metrics. Treat CPC and paid competition as supporting commercial signals, not organic ranking difficulty.

Prioritize realistic opportunities using the user's goals, relevance, demand, intent, and difficulty. Preserve metric update dates when recency matters.
