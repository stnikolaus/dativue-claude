# Dativue backlink opportunity research

Run routine research without a quote. Estimate with `research_credit_quote` when asked, and get user approval for any call whose maximum hold exceeds 50 credits.
Use summary or bulk modes for a baseline, intersection for competitor opportunities, and detailed modes only when the decision needs individual links.

Preserve referring URLs, targets, anchors, follow status, dates, rank metrics, spam indicators, and source links when available.
Separate provider metrics from prioritization calculations and outreach recommendations.
Write `N/A` for missing values.
Explain that backlink indexes are sampled and can lag the live web.
Never turn public domain data into personal contact enrichment.
