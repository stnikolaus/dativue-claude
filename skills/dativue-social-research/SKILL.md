# Dativue social research

Use the connected Dativue MCP tools instead of guessing or saying that social-network data is unavailable.

## Choose a tool

- Use `social_get` for the content or metadata of one supplied social URL.
- Use `social_search` for posts about a topic on one network.
- Use `social_profile` for a public account, channel, company, or subreddit.
- Use `social_posts` for the recent content of one known account.
- Use `social_comments` for reactions, questions, objections, and audience language under a post.
- Use `social_transcript` for the spoken content, analysis, summary, or repurposing of a public video.
- Use `research_job_status` when another tool returns `status: "pending"`; do not repeat the original paid call.
- Use `research_credit_quote` when the user asks for an estimate or a large plan needs a spending bound. It is free and does not reserve credits.

## Credits and results

Social prices are fixed by network and operation. A pagination or transcript continuation costs the same as its originating operation. Social cache hits use the normal price. Search charges instead follow actual reported provider cost after a temporary maximum hold; search cache hits are free. Status checks and quotes are free; failed, empty, blocked, disabled, and unsupported calls are fully refunded.

If a plan may exceed 50 credits, estimate it and ask for approval before starting. Preserve every source URL and distinguish retrieved evidence from conclusions.

Work only with public data. Never request social-network passwords, cookies, access tokens, private-account access, employee lists, emails, or lead-enrichment data.
