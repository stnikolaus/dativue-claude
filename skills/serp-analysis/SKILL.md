# Dativue SERP analysis

Use `search_serp` for the current top 10 Google results. Default to United States, English, and desktop only when the user has not specified another market or device.

Run routine research without a quote. Estimate with `research_credit_quote` when asked, and get user approval for any call whose maximum hold exceeds 50 credits.

Describe the dominant intent and content formats from the retrieved results. Separate observed SERP evidence from inferred opportunities. Account for featured snippets, People Also Ask, related searches, and video results when present. Cite original ranking URLs for claims about current results; do not imply that a result will remain in the same position.
