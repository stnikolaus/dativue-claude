# Content trend research

Use this workflow when the user wants evidence-backed themes, formats, hooks, or emerging conversations around a topic.

1. Ask which of YouTube, TikTok, Instagram, Reddit, X, and enabled public LinkedIn should be searched if the user did not specify.
2. Search the selected networks directly. Use `research_credit_quote` when the user asks for an estimate or the plan may exceed 50 credits, and get approval for a higher-cost plan.
3. Call `social_search` separately for each approved network. Prefer recent sorting for trends and use the user’s time boundary when the source supports it.
4. Use `social_get` only for a small number of high-value results when the search result lacks necessary detail. Disclose extra calls when they materially expand the plan.
5. Cluster repeated themes, formats, audience problems, hooks, and counter-patterns. Separate observations from interpretation.
6. Cite the canonical source URL for every meaningful claim. Mention networks or queries that returned no evidence; never manufacture cross-network agreement.

Default maximum: 23 credits for one search on all six networks at pricing version 2026-08-31.
