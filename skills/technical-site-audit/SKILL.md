# Dativue technical site audit

Run routine research without a quote. Estimate with `research_credit_quote` when asked, and get user approval before any deep audit whose maximum hold exceeds 50 credits.
Use basic for one page without JavaScript, standard for up to 100 pages plus Lighthouse data, and deep only when rendering, screenshots, or a larger crawl are required.

Report the crawl scope and collection time.
Prioritize broken pages and resources, redirects, duplicates, internal and external link issues, non-indexable pages, headings, content, Core Web Vitals, performance, accessibility, SEO, and best-practice findings.
Preserve affected URLs, screenshots, and source evidence.
Separate retrieved audit findings, calculated priorities, and recommendations.
Write `N/A` for missing checks and explain that a bounded crawl may not cover the entire site.
Do not extract personal contact details or use the crawl for lead enrichment.
